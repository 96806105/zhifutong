## 2. 核心模块职责

### 2.1 Core 层（core/）
- **llm.py**：`LLMClient` 类，封装 OpenAI 兼容接口（智谱 GLM），提供 `chat(...)` 与 `stream_chat(...)`（同步+异步）。
- **embeddings.py**：`embed_texts(texts)` 调用智谱 embedding 接口，返回向量。
- **config.py**：基于 `pydantic-settings` 读取 `.env`，类型安全。
- **logger.py**：统一日志（控制台 + 文件，RotatingFileHandler，分级）。
- **exceptions.py**：自定义业务异常体系（错误码节详述）。
- **middleware**：全局异常处理、请求日志、API 鉴权。

### 2.2 RAG 层（rag/）
- **loader.py**：加载 `knowledge_base/**/*.md`，记录分类（目录名）与文件名。
- **splitter.py**：中文友好的递归分块（`RecursiveCharacterTextSplitter`，分隔符含 `\n\n`、`\n`、`。`、`！`、`？`），保留元数据。
- **indexer.py**：文本 → embedding → 写入 Chroma（含 `category` 元数据）。
- **retriever.py**：相似度检索 + Top-K + 可选元数据过滤 + 基础重排（MMR 或阈值过滤）。
- **chain.py**：拼装 System Prompt + 检索上下文 + 历史，调用 LLM，输出最终答案 + 引用。

### 2.3 Dialog 层（dialog/）
- **session.py**：会话 ID 生成、会话生命周期。
- **memory.py**：滑动窗口历史（最近 N 轮），超限裁剪。
- **intent.py**：识别"转人工/闲聊/问题/情绪"等意图（关键词 + 规则 + LLM 辅助）。
- **transfer.py**：转人工决策引擎（明确请求 / 连续低置信度 / 负面情绪 / 敏感操作），生成工单号。
- **store.py**：对话记录持久化（SQLAlchemy + SQLite）。

### 2.4 API 层（api/）
- **chat.py**：`POST /api/chat`——入参 `session_id + message`，业务处理，返回 `text / sources / action`；流式变体返回 `SSE` 增量。
- **history.py**：`GET /api/history` 查历史会话。
- **kb.py**：`POST /api/kb/rebuild` 重建索引（管理员）。
- **admin.py**：管理接口（查看工单/统计）。

## 3. 关键流程设计

### 3.1 一次问答的完整时序
```
用户消息
  → 会话恢复（获取历史 N 轮）
  → 意图识别（转人工？闲聊？）
  → 若是转人工 → 生成工单 → 返回 action="transfer"
  → 否则走 RAG：
      问题向量化
      → Chroma 检索 Top-K（可带分类过滤）
      → 拼接 System + 历史 + 检索上下文
      → LLM 生成（流式推送 token）
      → 附加引用来源列表
  → 持久化本轮 user/assistant 消息
```

### 3.2 转人工决策树
```
[明确请求"转人工"] → 转人工
[连续3次低置信度]  → 转人工
[负面情绪关键词]   → 主动建议转人工
[敏感操作:退款/高权限] → 直接转人工
否则 → 正常回复
```

### 3.3 置信度评估
- 检索分数（embedding 余弦相似度）。
- 阈值：低于 `RETRIEVE_THRESHOLD`（如 0.45）视为"未命中"，返回兜底话术。
- LLM 回答要求自评（`confidence` 字段，0-1），低于阈值触发追问或转人工建议。

## 4. 数据库设计（对话历史）

```sql
-- 会话表
CREATE TABLE sessions (
    id            TEXT PRIMARY KEY,      -- uuid
    user_name     TEXT,                  -- 可选
    created_at    DATETIME,
    updated_at    DATETIME,
    status        TEXT DEFAULT 'open'    -- open / closed / transferred
);

-- 消息表
CREATE TABLE messages (
    id           INTEGER PRIMARY KEY AUTOINCREMENT,
    session_id   TEXT NOT NULL REFERENCES sessions(id),
    role         TEXT NOT NULL,          -- user / assistant / system
    content      TEXT NOT NULL,
    sources      TEXT,                   -- JSON 引用列表
    action       TEXT,                   -- none / transfer / fallback
    confidence   REAL,
    created_at   DATETIME
);

-- 工单表（转人工）
CREATE TABLE tickets (
    id          TEXT PRIMARY KEY,        -- TKT-XXXXXX
    session_id  TEXT,
    reason      TEXT,                    -- transfer 原因
    channel     TEXT DEFAULT 'chat',
    status      TEXT DEFAULT 'open',
    created_at  DATETIME
);
```

## 5. 接口契约

### POST /api/chat
```jsonc
// 请求
{ "session_id": "uuid-optional", "message": "我密码忘了怎么办？" }
// 响应（非流式）
{
  "session_id": "...",
  "reply": "重新设置密码的步骤：...",
  "sources": [{"title": "账号与密码faq", "category": "accounts", "score": 0.82}],
  "confidence": 0.9,
  "action": "none"          // none | transfer | fallback
}
```

### GET /api/chat/stream?session_id=..&message=.. （SSE 流式）
```
data: {"delta": "重新"}
data: {"delta": "设置"}
...
data: {"done": true, "reply": "...", "sources": [...], "action": "none"}
```

### POST /api/kb/rebuild
```jsonc
{ "message": "knowledge base rebuilt: 6 docs, 214 chunks", "count": 214 }
```

## 6. 技术架构决策记录（ADR 摘要）

| 决策 | 选择 | 备选 | 理由 |
|------|------|------|------|
| LLM 接入方式 | OpenAI 兼容 SDK（openai 包） | LangChain ChatOpenAI | 依赖少、流式稳定、讲解清晰、智谱原生兼容 |
| RAG 编排 | 自研轻量 pipeline | LangChain 全套 | 可控、性能好、面试可逐层讲解不依赖黑盒 |
| 向量库 | ChromaDB | Milvus | 本地零运维，开箱即用 |
| 存储 | SQLite + SQLAlchemy | Postgres | 单机演示足够，SQLAlchemy 便于平滑升级 |
| 流式 | SSE | WebSocket | 单向推送场景更合适、实现简单 |
| Config | pydantic-settings + .env | python-dotenv | 类型校验、环境变量原生 |

## 7. 非功能设计

- **日志分级**：`INFO`（请求/回复概览）、`WARNING`（低置信度）、`ERROR`（异常+堆栈）。
- **错误码体系**：`SUPPORT_LLM_TIMEOUT` / `SUPPORT_LLM_LIMIT` / `SUPPORT_RETRIEVE_FAIL` / `SUPPORT_PARAM_ERROR` / `SUPPORT_UNKNOWN`。
- **安全**：密钥在 `.env`（gitignore）；管理接口 token 鉴权；Prompt 注入防护；输出长度上限。
- **限流**：简单内存令牌桶，防滥用。
