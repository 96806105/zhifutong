# 03 - 技术选型

## 项目：智服通（企业 IT 技术支持智能客服）

---

## 1. 选型原则

1. **零基础可一周上线**：工具生态成熟、文档完善、社区活跃。
2. **对标企业级**：模块清晰、可测试、可 Docker 部署、可扩展。
3. **成本可控**：默认使用智谱 GLM 免费/低价模型，本地可跑。
4. **多模型兼容**：统一走 OpenAI 兼容接口（智谱原生支持），避免供应商锁定。

---

## 2. 技术栈总览

| 层 | 选型 | 理由 |
|----|------|------|
| 语言 | Python 3.10+（本机 3.14） | AI 生态首选，FastAPI/向量库原生支持 |
| Web 框架 | FastAPI | 异步高性能、自动 OpenAPI 文档、SSE 原生支持 |
| 模板引擎 | Jinja2 | 服务端渲染，避免前端脚手架复杂度，Visual 精致可实现 |
| LLM | 智谱 GLM-4-Flash | 免费、OpenAI 兼容、中文强 |
| Embedding | 智谱 Embedding-3 | 中文语义好，随 API 调用无需本地 GPU |
| RAG 编排 | LangChain 1.x | 组装加载/分块/向量/检索/链，成熟稳定 |
| 向量库 | ChromaDB 1.x | 轻量、嵌入式、纯本地，生产可平滑替换 Milvus |
| 数据库 | SQLite（内置）+ SQLAlchemy | 零配置、单文件，足够历史记录量级 |
| 前端 | HTML + CSS + JS（原生） | 无构建链路，快速、可控、精致 UI |
| 流式 | SSE（Server-Sent Events） | 单向服务器推送，比 WebSocket 简单可靠 |
| 配置 | pydantic-settings + .env | 类型安全的环境变量管理 |
| 日志 | Python logging + RotatingFileHandler | 分级日志 + 轮转文件 |
| 测试 | pytest | 标准、好用 |
| 部署 | Docker + docker-compose | 一键启动，可移植 |
| 代码规范 | Ruff（lint + format） | 快速、现代 |

## 4. 选型对比与原因

### LLM：为什么选智谱 GLM？
- **免费额度**：GLM-4-Flash 免费，适合冷启动演示。
- **中文优异**：面向中国企业 IT 场景，中文理解强。
- **OpenAI 兼容**：`https://open.bigmodel.cn/api/paas/v4`，可直接用 `openai` SDK。
- **未来可切换**：统一抽象层预留 DeepSeek/通义/Ollama 本地模型。

### 向量库：ChromaDB 而非 Milvus/Pinecone？
- Chroma 嵌入式本地运行，零运维，数据存本地目录，适合开源项目开箱即用。
- 代码层抽象 `VectorStore` 接口，生产环境可无痛换 Milvus（分布式、更大规模）。
- 中文对比：Pinecone 需科学上网；Milvus 需要 Docker 资源较重。

### 前端：为什么不用 React/Vue？
- 本项目一周交付，前端脚手架配置耗费大量时间（Webpack/Vite/依赖树）。
- Jinja2 + 原生前端 + 精致 CSS 完全能实现现代化的 Apple 风格聊天界面。
- 服务端渲染利于 SEO/首屏体验，代码量小好维护。

### 流式：SSE 而非 WebSocket？
- 客服场景是单向服务器推送，SSE 足够，且自动重连、实现简单。
- FastAPI 的 `StreamingResponse`/`sse-starlette` 原生支持。
- 浏览器原生 `EventSource` 支持，无需额外库。

## 5. 架构分层（技术选型视角）

```
[浏览器] 前端界面 (HTML/CSS/JS)
    ↓ HTTP / SSE
[FastAPI 应用层] api/chat, api/kb, api/session
    ↓
[业务层]
    ├── rag/      RAG管线（加载、分块、向量、检索、链）
    ├── dialog/   会话、记忆、意图、转人工
    └── core/     LLM抽象、Embedding、配置、日志、异常
    ↓
[数据层]
    ├── ChromaDB  向量知识库
    └── SQLite    对话历史
```

## 6. 风险与对策

| 风险 | 对策 |
|------|------|
| Python 3.14 与部分库不兼容 | 安装时逐库验证；如遇问题可降级到 3.12 虚拟环境 |
| GLM 免费模型限额/变慢 | 限流 + 优雅错误处理 + 可切换付费模型 |
| 零基础一周交付 | 模块化顺序开发（先 RAG 后对话再 UI），每阶段可运行 |
| 前端不惊艳 | 投入 Apple 风格设计 tokens + 精致细节（见设计篇） |
