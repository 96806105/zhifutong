# 05 · 飞书人工客服接线（双向）· 操作指南

> 把「转人工」从模拟工单升级为**真实人工**：员工在网页触发转人工后，
> 求助信息实时推送到飞书；人工客服在飞书里回复，回复自动回写会话，
> 员工在网页端实时看到人工答复。全程数据闭环。

---

## 1. 原理

```
员工(网页) ──转人工──► 智服通(建工单)
                          │  推送求助信息 + 工单号
                          ▼
                   飞书自建应用(机器人)
                          │  长连接(WebSocket) 常驻后台
                          ▼
                 人工客服在飞书群/单聊回复
                          │  收到 im.message.receive_v1 事件
                          ▼
                 智服通回写「人工回复」→ 网页轮询实时展示
```

关键点：飞书自建应用支持**长连接（WebSocket）事件订阅**，
无需公网回调地址，**本地任何网络环境可运行**。

---

## 2. 10 分钟开通（一次性操作）

### 2.1 创建应用

1. 登录 [飞书开放平台](https://open.feishu.cn/app) → 创建企业自建应用
2. 应用名称写「智服通客服」，头像随意
3. 在「机器人」里点击**启用机器人**（会自动添加到应用能力下）

### 2.2 配置权限

「权限管理」中搜索并开通：

- `im:message`（获取/发送消息）
- `im:message:send_as_bot`（以机器人身份发消息）

并在「应用发布」里**创建版本并发布**（可用白名单自测：发布范围选
「指定成员」含你自己，免管理员审核）。

### 2.3 事件订阅（关键）

「添加事件」「事件与回调 → 接收消息」：

- 订阅事件：**`接收消息 im.message.receive_v1`**
- 接收方式选择「使用长连接接收事件」
  （注意：如果后台是空的/默认了回调地址，先切到长连接模式）

### 2.4 拿到凭证

「凭证与基础信息」页复制：

- App ID
- App Secret

## 3. 配置智服通

编辑项目根 `.env`：

```ini
LARK_ENABLED=true
LARK_APP_ID=cli_xxxxxxxxxxxxxxxx
LARK_APP_SECRET=xxxxxxxxxxxxxxxxxxxxxxxx
# 方式A：把机器人拉进一个群，填群的 chat_id（推荐，多人值班）
LARK_NOTIFY_CHAT_ID=oc_xxxxxxxxxxxxxxxx
# 方式B（二选一）：机器人单聊给特定用户，填其 open_id
# LARK_NOTIFY_OPEN_ID=ou_xxxxxxxxxxxxxx
```

> chat_id 获取：在飞书中打开目标群 → 添加机器人进群 → 通过
> `im/v1/chats` 接口（或管理台）查询。open_id 可通过
> `contact/user` 接口按邮箱/手机查。

---

## 4. 启动

```bash
# 终端1：Web 服务（主进程）
python scripts/run.py

# 终端2：飞书长连接（后台人工通道）
python scripts/feishu_bot.py
```

启动后命令窗口会显示 ws 已连接。此时在网页触发「转人工」，
机器人立即把求助信息发到飞书接收方。

---

## 5. 人工回复的两种方式

| 方式 | 写法 | 适用 |
|---|---|---|
| 直接回复 | 直接发文字 | 单值班、按最近待处理工单绑定 |
| 指定工单回复 | `TKT-AB12CD 具体内容` | 多工单并发，精确到单 |

回复后：网页端对应会话在 3 秒内出现带有 **「人工回复」** 绿色标识的气泡，
工单自动标记为已处理。

## 6. 演示脚本（10 秒介绍）

> "当机器人判断用户需要真实支持时，会立即把工单推到我们的飞书客服群。
> 客服在群里回复，用户的网页端马上实时收到这段人工答复并标绿显示。
> 整个闭环不依赖公网，因为我们用的是飞书官方的长连接事件通道。"

## 7. 故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| `feishu not configured` | 未开 LARK_ENABLED / 缺凭证 | 检查 .env 三件套 |
| `notify failed: code=...` | 凭证错/权限缺/未发布应用 | 开放平台检查权限与发布 |
| 长连接启动报 401 | App Secret 错 | 复核凭证 |
| 能收到回复但没回写 | 无 open 工单 | 先让网页触发一次转人工 |
| 网页无「人工回复」 | 浏览器缓存旧 JS | Ctrl+F5 强刷 |
