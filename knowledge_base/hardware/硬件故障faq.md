# 硬件故障 FAQ

---

## 电脑无法开机

排查步骤：

1. 检查电源适配器连接是否稳固，电源指示灯是否亮起。
2. 长按电源键 10 秒强制关机后再开机。
3. 拔掉所有外设（U盘、打印线、外接硬盘）后开机。
4. 若听到异响或闻到焦味，立即断电并联系 IT。
5. 笔记本请检查电池电量，接上电源等待 5 分钟再试。

---

## 屏幕黑屏但主机运行

1. 按 `Win+P` 切换显示模式（复制/扩展/仅第二屏幕）。
2. 尝试重新插拔显示器视频线（DP/HDMI/VGA）。
3. 确认显示器电源与输入源正确。
4. 外接台式机可尝试更换接口（独显/集显）。
5. 仍黑屏，长按电源强制重启。

---

## 风扇噪音大 / 温度过高

常见原因与处理：

- 散热风扇积灰 → 办公室可申请 IT 除尘服务。
- 环境温度高 → 笔记本使用散热底座，保持出风口畅通。
- 后台高占用程序 → 打开任务管理器查看 CPU 占用，结束异常进程。
- 以上处理后仍高温 → 可能是硅脂老化，需送修。

---

## 键盘或鼠标无响应

1. 有线设备：重新插拔 USB 接口，尝试其他接口。
2. 无线设备：更换电池 / 重新配对（接收器重插+重连）。
3. 检查设备管理器是否出现感叹号（驱动异常）。
4. 重启电脑后再试。
5. 笔记本自带键盘失灵：试试外接USB键盘辅助排除。

---

## 外接显示器无法识别

1. 确认视频线插紧，检查接口是否支持该分辨率。
2. 在"显示设置"中点击"检测"按钮。
3. 尝试切换信号源（多接口显示器需要手动切换）。
4. 更新显卡驱动后重启。
5. 换一根线或换一个接口测试，判断是否线材损坏。

---

## 移动硬盘/U盘无法识别

1. 换一个 USB 接口（优先机箱后置接口）。
2. 检查"磁盘管理"，看是否未分配盘符（分配盘符即可）。
3. 检查移动硬盘是否需要外接电源。
4. 若磁盘管理中显示"损坏/RAW"，不要格式化，尽快联系 IT 数据恢复。

---

## 打印机无法打印

1. 确认打印机电源与纸张充足（排除卡纸，指示灯状态）。
2. 查看电脑端打印队列是否有卡住的任务，取消后重试。
3. 确认打印到正确的打印机（默认打印机可能已切换）。
4. 重启打印机和电脑。
5. 仍失败，记录打印机 IP/名称，提交工单并告知 IT。

---

## 电脑异常蓝屏 / 死机

1. 记录蓝屏错误代码（形如 `0x0000001E`）。
2. 重启进入安全模式（开机按 F8 / 设置-恢复-高级启动）。
3. 运行系统更新和病毒扫描。
4. 最近是否安装新软件/驱动，是则卸载。
5. 提供蓝屏代码或 dump 文件给 IT 分析。

---

## 电池续航变短

1. 关闭不用的后台程序与蓝牙。
2. 屏幕亮度降低，使用省电模式。
3. 长时间插电使用建议每两周放电一次校准。
4. 电池健康度低于 80%（在配套工具/系统设置可查）可申请更换电池。

---

## 接口（USB/网口/音频）损坏

硬件物理损坏请勿自行拆机，直接提交硬件维修工单。

- 保修期内：由 IT 协调厂商保修。
- 过保后：预估维修成本，由部门决定维修或更换。
- 备用设备可临时借用，需在 IT 登记。
