# 网络连接 FAQ

---

## 无法连接 Wi-Fi

排查步骤：

1. 确认 Wi-Fi 开关已打开（笔记本快捷键/飞行模式）。
2. 重启所在区域的无线路由器（若你有权限）。
3. 忘记当前网络后重新连接：设置 → 网络 → 忘记，再输入密码重连。
4. 检查是否连接的是公司正确 SSID（连接方式见下节）。
5. 仍然失败，查看是否提示"无法加入此网络"，拍下提示联系 IT。

---

## 公司 Wi-Fi 如何连接

1. 打开 Wi-Fi 列表，选择公司主 SSID（如 `Company_WIFI`）。
2. 使用工号作为用户名，域密码或动态密码登录。
3. 初次连接可能要求信任证书，选择同意。
4. 部分区域使用访客网络 `Company_Guest`，需在访客门户输入申请码。

## 网速很慢怎么处理

网速慢可能由以下原因引起：

- 同时在线设备过多（会议室高峰期）。
- 本地网络占用（大文件下载、视频会议、云同步）。
- DNS 异常（尝试切换为公共 DNS：8.8.8.8 或 223.5.5.5）。
- 无线信号弱（靠近路由器或使用有线）。

否则可通过 IT 支持测试工具对网络链路做测速诊断。

## 有线网络（网口）无法上网

1. 确认网线插紧，网口指示灯亮起。
2. 确认本地网络设置为"自动获取 IP"。
3. 释放并重新获取 IP：在终端输入 `ipconfig /release` 再 `ipconfig /renew`。
4. 如果显示"未识别的网络"，检查是否启用了代理软件（如 VPN client 冲突）。
5. 联系 IT 反馈工位网口信息，方便排查交换机端口。

---

## VPN 无法连接

VPN 常见故障：

1. 确认已安装最新版 VPN 客户端，以管理员身份运行。
2. 检查网络是否正常（本地网络不通，VPN 无法建立）。
3. 确认动态口令正确且未过期（令牌 30 秒刷新一次）。
4. 尝试切换 VPN 接入点（如总部/华东/华南节点）。
5. 查看客户端系统日志，或将错误码反馈给 IT。

## 配置 DNS

Windows：
1. 打开"网络和共享中心" → 更改适配器设置。
2. 右键当前网卡 → 属性 → Internet 协议版本 4 (TCP/IPv4)。
3. 选择"使用下面的 DNS 服务器地址"。
4. 首选 223.5.5.5，备用 114.114.114.114，点击确定。

Mac：
系统偏好设置 → 网络 → 详细信息 → DNS → 添加服务器。

## 远程办公网络问题（居家）

居家办公网络问题建议优先检查：

- 家庭路由器重启（断电 10 秒再通电）。
- 使用 5G Wi-Fi 频段减少干扰。
- 关闭占用带宽的下载/视频应用。
- 若使用公司配发笔记本，确认补丁已更新。
- 视频会议卡顿可尝试切换到手机热点对比排除。

## IP 地址冲突

如果提示 IP 地址冲突：

1. 在终端执行 `ipconfig /release` 后重启网卡。
2. 再执行 `ipconfig /renew` 重新获取 IP。
3. 若频繁冲突，建议在路由器/交换机中将该设备改为固定 IP（需 IT 协助）。
4. 排查是否有蹭网设备或私接路由器导致 DHCP 冲突。

---

## 科学上网/访问海外站点受限

公司出口带宽受安全策略限制，部分海外站点可能无法访问，属正常安全策略。

- 业务需要访问海外系统，需通过 IT 申请白名单。
- 严禁私自使用第三方代理（违规风险）。
- 申请白名单请说明业务用途与访问时长。
